# Being Found on Google: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `dartssam.co.uk` readable and indexable by search engines, with
pages worded for the searches people make ("free darts autoscorer",
"autodarts alternative").

**Architecture:**
- A new `server/seo.py` holds everything search-related for the hosted site:
  `robots.txt`, the sitemap, "don't list this" at the app address, sending
  `home.html` for `/` at the home address, and the per-page `<head>` lines
  (canonical address, preview card, structured data).
- `server/host.py` changes in two lines only, because another session is
  editing that file.
- The home page and the two new pages are plain static HTML in `web/`, in the
  site's existing `.site` style.

**Tech Stack:** FastAPI/Starlette (Python), plain HTML/CSS. Tests are
script-style (`python -m tests.test_seo`), run with all the others by
`python -m tests`.

**Spec:** `docs/superpowers/specs/2026-11-23-search-design.md`

## Global Constraints

- **Commit from a private index.** Another session is editing
  `server/host.py`, `tests/test_host.py`, `web/faq.html`, `web/privacy.html`,
  `docs/hosting.md` and `tools/backup.sh`. Use
  `GIT_INDEX_FILE=<tmp> git read-tree HEAD`. For a shared file, stage only your
  own hunks applied onto HEAD's copy. Afterwards run `git reset -- <files>` in
  the real index, and check `git diff --cached --stat` before each commit.
- **No full address written into any file.** It comes from the settings:
  `"home"` (or `"site"` when there is no separate home address).
- **Copy follows the "genuine, not AI" conventions:**
  - plain documents in the README's voice
  - descriptive headings
  - real screenshots, each with a caption
  - none of: slogan headlines, eyebrow labels, card grids, tables of ticks, or
    closing call-to-action slogans
  - search words used only where a person would naturally say them
- **Every claim about Autodarts or DartCounter** is checked on their own site,
  links to its source, and sits on a page that says "Checked on <date>".
- **Sam approves before the pages are committed.** That covers the wording of
  `home.html`, `compare.html` and `autoscoring.html`, because the repo is
  public.
- **With one address (no `"home"` setting, or `"home"` equal to `"site"`),**
  `/` stays `index.html`, nothing gets the noindex header, and only the head
  lines and `robots.txt`/`sitemap.xml` are added.

## Review Focus

1. **Signed-in players opening dartssam.co.uk.** They now get `home.html`, not
   the app. Its "Open the app" link (`play`) must take them to the app address,
   and `./#signin` links from the other pages must still end up at the app's
   sign-in. Covered by the `/play` and `#signin` checks in Tasks 1 and 2.
2. **A request whose Host is neither address** (the bare IP, an old name). It
   must get the noindex header and never the home page. Covered by an assertion
   in Task 2.
3. **A page with no `<title>` or description**, such as `index.html` at the app
   address or a missing file. `head()` must give lines without crashing, or
   nothing. Covered by an assertion in Task 2.
4. **Page text containing `"`, `<` or `&`** in a title or description must be
   escaped in the `og:` lines, and the JSON-LD must stay valid JSON. Covered by
   an assertion in Task 2.
5. **The service worker on returning visitors** (network-first with a time
   limit, `web/sw.js`). The new `home.html` must be served, not an old cached
   `index.html`, and `home.html` must not register a service worker. Checked by
   hand in Task 2, step 7.

  `head=lambda scope: page_head(scope) + search.head(scope)`. Before it, add
  `search = seo.Search(WEB, site, home); search.install(app)`, placed before
  `vision_files(app)`, after the `home`/`site` lines.

- [ ] **Step 3: Write `server/seo.py`.** Start it with the licence header, as
  every server file has.
  - **Which address a request is for:** compare the request's `host` header
    with `urlsplit(home).netloc`. A request is "at home" only when `home` is set
    and the two match.
  - **Middleware (`@app.middleware("http")`):**
    - When at home and the path is `/`, set `request.scope["path"] = "/home.html"`.
    - When `home` is set and the request isn't at home, add
      `X-Robots-Tag: noindex` to the response.
  - **`/robots.txt`:** `User-agent: *\nAllow: /\n`, plus
    `Sitemap: <home or site>/sitemap.xml\n` when at home, or when there is one
    address.
  - **`/sitemap.xml`:** a `<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">`
    with one `<url><loc>` per entry in `PAGES`, and no `lastmod`. It's a 404
    when `home` is set and the request isn't at home.
  - **`/play`:** a 302 to `site + "/"`.
  - **`head(scope)`:**
    - Work out the page from `scope["path"]`: `/`, `/index.html` and
      `/home.html` all become `""`.
    - Read `<title>` and `<meta name="description">` from the file once and
      keep them (use `functools.cache`).
    - Lines given:
      - always: `canonical`
      - when the page has a title: `og:title`, `og:description`, `og:url`,
        `og:image` (`<base>/shots/share.jpg`), `og:type` website,
        `og:site_name` "Darts S.A.M" and
        `twitter:card` `summary_large_image`
      - when the page is `""` and the request is at home (or there is one
        address): JSON-LD
    - Escape everything with `html.escape(..., quote=True)`.
  - **The JSON-LD:** `json.dumps(..., indent=1, ensure_ascii=False)` of
    `{"@context": "https://schema.org", "@type": "SoftwareApplication",
    "name": "Darts S.A.M", "applicationCategory": "SportsApplication",
    "operatingSystem": "Web, Windows, macOS, Linux", "description": <the
    page's description>, "url": <base>/, "image": <base>/shots/share.jpg,
    "offers": {"@type": "Offer", "price": "0", "priceCurrency": "GBP"}}`.
    Before putting it in the page, replace `</` with `<\/`.
